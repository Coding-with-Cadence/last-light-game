THE LAST LIGHT II — ANDROID PWA PACKAGE

This is a Progressive Web App package, not an APK. To install on Android, first host it on an HTTPS address.

FREE HOSTING WITH GITHUB PAGES
1. On a phone or computer, sign in at github.com or create a free account.
2. Create a new PUBLIC repository named last-light-game.
3. Upload every file in this ZIP to the repository root: index.html, manifest.webmanifest, sw.js, icon.svg.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch. Choose branch main and folder /(root), then Save.
6. Wait for the Pages URL to appear. It will look like https://YOUR-USERNAME.github.io/last-light-game/
7. Open that URL in Chrome on your Android phone.
8. Tap Chrome's three-dot menu > Install app (or Add to Home screen) > Install.
9. Launch the game from your home screen.

The game saves basic character progress in browser local storage on that device. Clearing Chrome site data may erase it. This prototype is not a native APK and has not been published to Google Play.
